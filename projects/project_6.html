Operation Yggdrasil

Summary

Named after the mythological world-tree connecting the nine realms, Operation Yggdrasil is an AI-powered Open Source Intelligence (OSINT) platform that aggregates publicly available records and transforms unstructured text into interactive entity-relationship graphs—precursor to my later 3D MCP-enabled PROJECT ARGUS architecture.

Key Features

  • LLM-Powered Entity & Relation Extraction: Uses frontier NLP models to extract people, domains, organizations, locations, and semantic relationships from unstructured public sources.
  • Multi-Source Public Data Aggregation: Consolidates open web records, public registries, and social metadata into normalized entity profiles.
  • Interactive Cytoscape.js Link Analysis: Renders dynamic node-edge graphs to uncover multi-hop connections and shared infrastructure.
  • Geospatial Correlation: Maps location metadata to highlight physical clusters and regional patterns.
  • Automated Intelligence Dossiers: Exports structured investigative summaries complete with graph snapshots and source citations.
  • Strict Ethical OSINT Guardrails: Operates exclusively on lawful, publicly accessible data sources.

Tech Stack

  • Frontend: React.js, Cytoscape.js Graph Visualization
  • Backend: Python, Flask, BeautifulSoup & Selenium Collectors
  • AI / NLP: OpenAI / LLM Entity Extraction & Summarization APIs
  • Database: PostgreSQL

Theory & Architecture

Information overload is the primary adversary in modern investigations. Every public record or domain registration is a single leaf; Operation Yggdrasil builds the trunk and branches—combining automated NLP entity resolution with interactive graph visualization so analysts see the entire connected system at a glance.

Self-Taught AI University

Summary

Self-Taught AI University is a flagship Run Nexus application engineered to deliver rigorous, interactive mastery across computer science, mathematics, AI/ML engineering, physics, cybersecurity, and systems design. Rather than serving static pre-recorded videos, the platform orchestrates frontier Gemini models to synthesize 8,300+ deep, textbook-caliber lessons across 285 structured courses—complete with interactive JavaScript simulations, executable coding & mathematical proof labs, rubric-driven LLM evaluation, and neural text-to-speech audio lectures.

Key Features

  • 285 Structured Courses & 8,300+ Live Lessons: Covers undergraduate-to-graduate curricula with prerequisite graphs, modular syllabi, worked derivations, and real-world engineering case studies.
  • Zero-Latency Background Lesson Prefetcher: Asynchronous worker queue pre-generates upcoming syllabus modules in SQLite while the student studies the current lesson, eliminating LLM wait times.
  • Interactive JS Simulations & Python Code Labs: Dynamically embeds interactive HTML5 Canvas / JS visualizers and sandboxed coding exercises tailored to each mathematical or algorithmic concept.
  • Rubric-Based LLM Proof & Code Grading: Evaluates free-response derivations, architecture designs, and code submissions against structured multi-criteria rubrics with targeted Socratic feedback.
  • Neural Edge-TTS Audio & Gamified Progression: Streams natural neural voice narration alongside persistent SQLite XP tracking, mastery streaks, and academic rank progression.

Tech Stack

  • Generative AI Core: Google Gemini Pro / Flash APIs, Structured JSON Syllabus & Lesson Synthesis, Socratic Grader Prompts
  • Backend & Queueing: Python, Flask, Multi-Threaded Async Prefetch Workers, SQLite Content & Progress Vault
  • Audio & Interactive UI: Microsoft Edge-TTS Neural Voice Pipeline, KaTeX Math Rendering, Sandbox JS/Canvas Widgets

Theory & Architecture

Most AI tutors fail because they act like unstructured chat boxes—answering isolated questions without curricular scaffolding or active verification. Self-Taught AI University pairs the generative depth of LLMs with deterministic instructional architecture: structured syllabi, predictive caching for instant UX, interactive manipulation of variables, and rigorous rubric-based assessment.

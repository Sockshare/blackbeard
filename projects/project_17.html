Due-Diligence Room: 5-Agent SEC EDGAR & Forensic Memo Studio

Summary

Due-Diligence Room is a local-first multi-agent financial research war room that produces institutional-grade investment memos with zero unverified numbers. Given any US ticker (or private-company documents), five specialized agents—Financial Analyst, Forensic Accountant, Legal & Governance Reviewer, Short-Seller Skeptic, and Managing Editor—work over a shared evidence blackboard streamed live via Server-Sent Events (SSE), where every claim and ratio links directly to its exact SEC filing accession number or document snippet.

Key Features

  • Live SEC EDGAR XBRL & 10-K Ingestion: Fetches multi-year GAAP CompanyFacts and recent 10-K/10-Q filings directly from data.sec.gov with compliant rate-limiting and local caching.
  • Deterministic Forensic Accounting Suite: Computes all 8 Beneish M-Score ratios (DSRI, GMI, AQI, SGI, DEPI, SGAI, LVGI, TATA), Altman Z / Z''-Scores, 9-point Piotroski F-Score, Sloan Accrual Ratio, and FCF conversion in pure Python—never delegated to LLM arithmetic.
  • Mandatory Adversarial Skeptic & Rebuttal Loop: Requires the Skeptic agent to build the strongest evidence-backed bear case and attack every optimistic assumption before the Analyst and Forensic Accountant issue rebuttals.
  • Zero-Hallucination Citation Verification Gate: Enforces an automated verification pass confirming 0 unsourced figures and valid [ev:ID] provenance chips across every section of the finished memo.
  • Interactive Human Checkpoint & Export: Allows analysts to pin custom thesis questions, inspect raw evidence cards, and export standalone HTML or Markdown investment memos.

Tech Stack

  • Agent Blackboard & Streaming: Python, FastAPI, Server-Sent Events (SSE), SQLite Evidence & Claim Ledger
  • Forensic & Financial Math: Pure-Python XBRL Normalizer, Beneish M-Score, Altman Z-Score, Piotroski F-Score, DuPont ROE
  • Data & Document Parsing: SEC EDGAR REST APIs, pypdf Local PDF Extractor, CSV Financial Parser
  • LLM & Offline Architecture: 100% Functional Deterministic Synthesis Mode + Optional Ollama / Gemini / OpenAI / Anthropic LLM Enhancement

Theory & Architecture

Single-prompt LLM stock summaries suffer from sycophancy, arithmetic hallucination, and recency bias. Due-Diligence Room solves all three architectural flaws: Python computes every financial ratio deterministically from primary XBRL filings, a dedicated Skeptic agent enforces structural adversarial tension, and a strict citation gate rejects any prose number that cannot trace back to a registered evidence artifact.

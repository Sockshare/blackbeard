NeonTouch Synth: 10-Finger Ephemeral Light & Polyphonic Cyberdeck Studio

Summary

NeonTouch Synth (featuring the Night City Cyberdeck console on Port 8112) is a zero-dependency multi-touch musical light instrument and cyberpunk DJ workstation engineered for ultra-low CPU and smooth 60 FPS rendering even inside headless Wayland or Chrome Remote Desktop environments—with zero camera or microphone permissions.

Key Features

  • 1-to-10 Finger Ephemeral Light & Polyphonic Synthesis: Maps simultaneous touch points, pointer drags, and multi-line fans (1, 2, 3, 5, 10 lines) across 10 cyberpunk darksynth timbres (BladeLead, Supersaw, Acid303, ReeseBass, CyberStab, DarkChoir, 808Slam, NightPluck, LaserZap, RainChime) locked to a Minor/Phrygian scale so every solo stays harmonic.
  • Procedural Cyberpunk Song Generator & Song Scene Arranger: Synthesizes fresh darksynth beats, gritty basslines, chord progressions, and codenamed tracks on tap across 4 curated grooves (NIGHT_CITY // 2077, OUTRUN_CHASE // HWY, BOSS_FIGHT // MECH, NEON_RAIN // 2049) plus a live 16-step neon sequencer grid.
  • Dual Holo-Turntables, Punch-In Glitch FX & Cyber Vocoder: Includes interactive jog wheels with crossfader blending, Kaoss-style punch-in glitch effects, and a synthetic cyber vocoder built purely with Web Audio DSP nodes.
  • Kaleidoscope Symmetry Lasers & Live Skyline FFT: Mirrors ephemeral touch trails and concentric tap ripples into 2-way or 4-way laser symmetry alongside real-time skyline FFT frequency bars and cyber target reticles, plus a built-in mix exporter.
  • Zero-Dependency Python ThreadingHTTPServer & Automated Verification: Served cleanly via Python standard library (server.py) with GET /api/health capability reporting and verified by tests/test_omnisense.py.

Tech Stack

  • Audio DSP Engine: Native Web Audio API oscillators, resonant filters, envelopes, delay/reverb routing, 16-step sequencer clock, and live mix recorder
  • Visual Canvas Renderer: VM-optimized HTML5 2D Canvas (RENDER_SCALE = 0.55, 22ms frame budget) with plasma trails, kaleidoscope symmetry, reticles, and skyline FFT bars
  • Backend & Server: Zero-dependency Python 3 ThreadingHTTPServer (server.py) exposing /, /api/health, and /static/*
  • Test Suite: Automated integration test (tests/test_omnisense.py) verifying all 10 cyberdeck features, static asset delivery, and strict removal of camera/mic endpoints

Design Philosophy

Most browser synth toys choke remote desktop VMs with heavy WebGL shaders or require fragile webcam/mic permissions. NeonTouch Synth replaces external hardware tracking with pure multitouch + keyboard + pointer kinematics, quantizes pitch to a dark Minor/Phrygian scale so rapid 10-finger chords sound musical immediately, and caps offscreen raster resolution at 0.55x scale to preserve silky 60 FPS audio-visual responsiveness anywhere.

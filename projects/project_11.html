PROJECT ARGUS: Autonomous 3D OSINT & Custom MCP Server

Summary

PROJECT ARGUS is a next-generation geospatial intelligence platform and custom Model Context Protocol (MCP) server hosted within Run Nexus. While humans interact with ARGUS through a high-frame-rate 3D WebGL orbital globe visualizing live global telemetry, LLM agents connect directly to ARGUS's custom MCP server (mcp_server.py)—calling strongly typed tools across 11 intelligence disciplines to perform autonomous multi-hop reconnaissance, infrastructure correlation, and anomaly triage.

Key Features

  • Custom Model Context Protocol (MCP) Server: Exposes deterministic, schema-validated MCP tools over JSON-RPC so Claude, Gemini, and custom agent loops can query live external intelligence without brittle screen-scraping.
  • 11 Live Intelligence Disciplines: Unifies ADS-B Aviation tracking, NORAD/TLE Orbital Satellites, BGP Routing & ASN telemetry, Certificate Transparency & DNS, Cyber Threat Feeds, Seismic sensors, Maritime AIS, NOAA Space/Weather, RF Spectrum, and Geopolitical events.
  • Interactive 3D WebGL Geospatial Command Deck: Renders thousands of concurrent moving entities, orbital arcs, and network vector overlays on a hardware-accelerated 3D globe.
  • Autonomous Multi-Hop Agent Investigations: Enables an LLM agent to pivot seamlessly from a suspicious domain -> ASN/BGP prefix -> TLS certificate -> physical PoP coordinates -> regional infrastructure alerts in a single reasoning loop.
  • Rate-Limited Caching & Resilient Fallbacks: Implements intelligent TTL caching, circuit breakers, and normalized Pydantic/JSON schemas so agent tool calls remain fast and deterministic.

Tech Stack

  • MCP & Agent Interface: Python Model Context Protocol (MCP) SDK, JSON-RPC 2.0, Typed Tool Schemas
  • Backend & Ingestion: Python, Flask / Async HTTP Collectors, GeoJSON & TLE Orbital Propagators
  • 3D Visualization: Three.js / Globe.gl WebGL Shaders, Spatial HUD Overlays, Real-Time Telemetry Bus
  • Data Disciplines: OpenSky ADS-B, CelesTrak TLE, RIPE/BGP, crt.sh TLS, USGS, Threat Intel APIs

Theory & Architecture

LLMs are extraordinary reasoning engines trapped behind static training cutoffs unless given clean sensory organs. Model Context Protocol (MCP) is the universal USB-C port for AI agency. By wrapping 11 heterogeneous real-world telemetry APIs behind a unified MCP tool server, PROJECT ARGUS transforms an LLM from a passive text generator into a live situational-awareness analyst capable of grounding every hypothesis in real-time global data.

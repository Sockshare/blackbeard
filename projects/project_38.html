AiLabs: 2-in-1 Agentic Coding IDE, Embedded SkillForge AI Studio & 41 Deterministic Auditors

Summary

AiLabs (Port 8120, integrated into Run Nexus and natively mounting SkillForge AI as a 2-in-1 studio) is a clean-room, zero-dependency 11-Page Multi-Provider Agentic Coding IDE, Deterministic Security & Code Quality Workbench, and Local Ollama AI Guardrails Lab. Unifying Local Ollama, Google Gemini, Anthropic Claude, and OpenAI behind 22 native tools, 43 built-in progressive-disclosure skills (41 executable deterministic auditors), live SSE tool-call diffs, local binary RAG, chainable workflows, scheduled monitors, and a live MCP/HTTP test bench, AiLabs runs from a single zero-pip Python server.

Key Capabilities (v2 / 11 Dedicated Pages)

  • Prompting Canvas with Live Tool-Call Streaming, Inline File Diffs & Direct Execution (/): Streams live SSE tokens, mid-turn tool_start/tool_result cards, and colorized unified file diffs; executes Python/Bash code blocks directly via ▶ Run; attaches drag-and-drop .pdf, .docx, .xlsx, .zip, code & vision images; and pairs Personas, Web Search, and Local RAG toggles.
  • 41 Built-in Deterministic Auditors, Parallel Batch Suites & Closed-Loop ✨ Fix with AI (/audits): Ships 41 zero-dependency auditors spanning AppSec/SAST (8), CloudSec/K8s/IaC (5), Supply Chain/CI/CD (4), SOC/Blue Team (6), AI/Data/Agentic Security (5), Code Quality/AST Complexity (5), and InfoSec GRC (8)—each verified with canonical SHA-256 determinism. Run single skills or parallel domain/full-repo suites for a 0–100 Posture Score, then click ✨ Fix with AI to generate a surgical patch, preview the diff, apply with 1-click Undo, and prove the fix via deterministic re-scan.
  • 2-in-1 Embedded SkillForge Studio & Portable Skill Manager (/skills & /builder): Browse 43 built-in skills alongside your created skills, import/export portable .zip / SKILL.md / raw URL packages with traversal & clean-room hygiene checks, compile standalone skills & orchestrators, and optimize trigger descriptions across a 60/40 split.
  • Chainable Workflow Pipelines, Scheduled Monitors & 4-Layer Local Ollama Guardrails Lab (/automations & /guardrails): Chain deterministic audits → shell tests → RAG retrieval → LLM synthesis with live SSE progress and recurring background monitors; benchmark Unprotected Raw Local Ollama side-by-side against a 4-layer defense pipeline (Input Classifier, XML Isolation, PreToolUse Tool Allowlist, Exact/Reversed/Base64 Canary Redactor).
  • Local Binary RAG, Model Arena, Live Terminal, HTTP Security Header Tester & MCP/Hooks Studio (/knowledge, /arena, /workspace, /settings): Zero-pip .pdf/.docx/.xlsx/.zip RAG powered by Ollama nomic-embed-text; side-by-side Model Arena; live SSE terminal with Kill switch & history; live REST API & passive A–F security header grader; Ollama RAM/Model manager; live MCP JSON-RPC Inspector & Tool Tester; and interactive AGENTS.md / .ailabs/rules/*.md & custom PreToolUse Hooks editor.

Tech Stack

  • Zero-Dependency Python Core: 100% Python 3.10+ Standard Library (Zero pip dependencies), 22 Native Tools (tools.py), Streaming ReAct Loop with Inline Diffs (agent_loop.py), Embedded SkillForge Mount (skillforge_mount.py)
  • Audits, Remediation & Automation: 41 Deterministic scripts/audit.py Engines, Parallel Batch Suite Runner (audit_runner.py), Closed-Loop Patch/Undo/Verify (audit_remediator.py), Chainable Workflows (workflows.py), Background Scheduler (sidecars.py)
  • RAG, Guardrails & Developer Tools: Pure-Stdlib Binary Parser for PDF/DOCX/XLSX/ZIP (doc_parser.py), Local Vector/Lexical RAG (knowledge.py), 4-Layer Ollama Guardrails Lab (guardrails_lab.py), Live SSE Terminal (terminal_runner.py), HTTP/API Header Grader (http_tester.py), Live MCP Hub (mcp_hub.py)
  • Multi-Page UI & Automated Verification: 11 Focused Vanilla HTML5/CSS3/ES6 Pages + 19-Test Automated Verification & Clean-Room Suite (tests/test_ailabs.py)

Theory & Architecture

Modern agentic coding platforms earn trust when stochastic LLM reasoning is anchored by deterministic systems engineering: progressive skill disclosure and lazy MCP schema files protect the context window; canonical SHA-256 audit scripts eliminate flaky security checks; closed-loop remediation proves every AI patch by re-running the exact deterministic rule that fired; PreToolUse hooks enforce guardrails outside the model; and isolated git worktree subagents prevent parallel edit collisions. AiLabs unites that entire stack—plus an offline Local Ollama Guardrails Lab and SkillForge Builder—in one portable repository with zero external dependencies.

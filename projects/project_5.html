Operation Icarus

Summary

Operation Icarus is a stealth-oriented Nmap command overlay engineered to give network defenders and penetration testers an intuitive, multi-tabbed web interface for complex scan orchestration, low-noise timing templates, and NSE script execution—complete with persistent PostgreSQL scan history and visual topology mapping.

Key Features

  • Stealth Scan Profile Cards: Interactive presets explaining timing templates, packet fragmentation, and decoy flags for low-noise reconnaissance.
  • Persistent Scan History & Diffing: PostgreSQL-backed dashboard to inspect, export, compare, or re-run historical network sweeps.
  • Multi-Tab Concurrent Scan Sessions: Manage simultaneous subnet discovery and deep port/service enumerations in parallel tabs.
  • Live Streaming Progress & Collapsible Logs: Real-time stdout streaming with progress indicators and clean structured parsing.
  • Visual Network Maps & Heatmaps: Transforms raw XML/text Nmap output into host topology graphs, port distribution charts, and risk heatmaps.
  • Categorized NSE Script Browser: Searchable catalog of Nmap Scripting Engine modules with parameter builders and safety ratings.

Tech Stack

  • Frontend: HTML5, CSS3, JavaScript, Interactive Charting
  • Backend: Python, Flask Subprocess Streamer
  • Database: PostgreSQL
  • Recon Engine: Nmap, Nmap Scripting Engine (NSE)

Theory & Architecture

Command-line reconnaissance across dozens of subnets quickly produces terminal fatigue and missed host changes. Operation Icarus bridges raw CLI power with structured visual situational awareness—preserving full control over stealth packet parameters while making scan telemetry immediately interpretable.

Vulnerability Verifier & Supply-Chain Provenance Suite

Summary

The Vulnerability Verifier & Supply-Chain Provenance Suite bridges application vulnerability governance and software supply-chain integrity inside Run Nexus. It pairs an autonomous SLO compliance engine (deployed both as a standalone web application on port 8090 and as a portable Jetski/Claude-compatible SKILL.md AI Agent Skill) with the BCID Binary Provenance Checker for verifying SLSA Level 3/4 cryptographic build attestations and hermetic CI/CD enforcement.

Key Features

  • Dual Deployment: Web Agent + Portable SKILL.md: Operates interactively via a Run Nexus web console or headlessly as a declarative AI Agent Skill invoked directly inside agentic coding sessions.
  • Deterministic P0–P3 Remediation SLO Engine: Computes exact ticket age, grace windows, severity-tier SLA thresholds, and breach trajectories across multi-component security backlogs.
  • BCID & SLSA Supply-Chain Provenance Verification: Audits production binary artifacts for verified source control lineage, two-party code review attestations, and non-falsifiable build provenance.
  • 13-Widget Live Burn-Down & Workspace Automation: Programmatically populates cloud spreadsheets and executive dashboards via REST APIs with 13 live KPI widgets, severity distributions, and aging histograms.
  • One-Click Executive Audit Bundles: Generates publication-ready HTML, DOCX, Markdown, CSV, XLSX, high-DPI Matplotlib charts, and SHA-verified ZIP evidence archives.

Tech Stack

  • Agentic Packaging: SKILL.md Declarative Agent Specification, MCP & REST API Connectors
  • Backend & Analytics: Python, Flask, Pandas, Matplotlib, python-docx, OpenPyXL
  • Supply-Chain Security: SLSA L3/L4 Attestation Verification, Binary Provenance Policy Engine
  • Cloud Automation: OAuth2 REST APIs for Automated Cloud Docs & Live KPI Sheets

Theory & Architecture

Security posture degrades silently when vulnerability SLAs and build provenance checks rely on point-in-time manual spot checks. Packaging the entire verification pipeline as both a web microservice and a first-class AI Agent Skill means any autonomous agent can audit a system's open vulnerabilities and supply-chain attestations in seconds, producing boardroom-ready metrics and immutable audit trails.

Run Nexus & Skill Holders Studio

Summary

Run Nexus is a full-stack AI operating hub and microservice control plane engineered to launch, monitor, and interconnect 14+ specialized LLM applications, security audit workbenches, 3D/media studios, and CLI automation suites from a single unified interface. Integrated directly into the core platform via a modular Flask Blueprint is Skill Holders Studio—an interactive engineering environment for authoring, validating, testing, and packaging reusable AI Agent Skills (SKILL.md specifications, helper scripts, and MCP tool schemas) so autonomous LLM agents can execute complex domain workflows deterministically.

Key Features

  • Unified 14-App Microservice Control Plane: Manages port allocation, health polling, subprocess spawning, graceful termination, and real-time Server-Sent Events (SSE) log streaming across 14+ web apps and CLI suites.
  • Skill Holders Studio (Portable Agent Skills): Provides a dedicated studio for crafting structured SKILL.md instructions, YAML frontmatter triggers, execution guardrails, and reference scripts for LLM agents.
  • MCP & Tool-Use Readiness: Standardizes how local Python utilities, REST connectors, and domain parsers expose structured capabilities to Model Context Protocol (MCP) clients and multi-agent runners.
  • Integrated Storage & Artifact Manager: Tracks generated reports, model outputs, SQLite state stores, and media assets across isolated application workspaces with one-click inspection.
  • Zero-Friction Developer Ergonomics: Eliminates terminal sprawl by giving every AI agent, compliance workbench, and generative pipeline a consistent launchpad and telemetry bus.

Tech Stack

  • Core Backend: Python 3, Flask, Modular Blueprints, Subprocess & Signal Orchestration
  • Agentic Layer: SKILL.md Specification Engine, Model Context Protocol (MCP) Bridges, Gemini & OpenAI SDKs
  • Frontend UI: HTML5, Modern Glassmorphic CSS3, Vanilla JS, Server-Sent Events (SSE)
  • Persistence & Config: Declarative apps.json Registry, SQLite State Stores, Local Artifact Vaults

Theory & Architecture

Building a single AI prototype is easy; operating a fleet of over a dozen specialized multi-agent systems without drowning in port conflicts, scattered scripts, and duplicated prompt logic requires systems engineering. Run Nexus treats AI workflows as composable microservices and codifies domain expertise into portable Agent Skills. Instead of re-prompting an LLM from scratch every session, Skill Holders Studio turns proven engineering playbooks into versioned, machine-readable capabilities that any MCP-capable agent can invoke on demand.

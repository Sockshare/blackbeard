SkillForge AI: 1:1 Skill Builder (skill-creator) & Multi-Skill Orchestrator Studio

Summary

SkillForge AI (standalone on Port 8108 AND natively embedded inside AiLabs on Port 8120 via /builder) is a clean-room, zero-dependency, local-first 1:1 Skill Builder (skill-creator) Studio, Web-App-to-Headless-CLI Decoupler, Multi-Skill Sequential Orchestrator, and 56-Tool MCP Compiler Hub. Powered natively by Local Ollama (auto-discovering any installed model) alongside Google Gemini, Anthropic Claude, and OpenAI, it turns natural-language workflows or local web apps into verified, portable SKILL.md packages (~/.ailabs/config/skills/) and deterministic multi-stage orchestration pipelines.

Key Features

  • 1:1 skill-creator Workbench (Interview → Synthesize → Eval → Iterate → Optimize): Guides users through structured LLM intent & edge-case interviews, synthesizes self-contained SKILL.md + scripts/ + references/ + evals/evals.json packages, runs real paired with_skill vs. without_skill/old_skill subprocess evaluations on disk, generates an interactive standalone HTML Eval Viewer, applies feedback.json rewrites, and optimizes YAML trigger descriptions using a 60/40 train/held-out split.
  • Dual Web-App Compilation (Live MCP Server OR Pure Headless CLI Decoupling): Point SkillForge AI at any local application (including bundled TaskPulse on :8110 and BillingOps on :8115) to either expose live HTTP routes as MCP JSON-RPC 2.0 tools OR strip HTTP/UI boilerplate via Python AST into a 100% standalone headless CLI skill that runs with zero web server running.
  • Sequential Multi-Skill Orchestration & 2-Run SHA-256 Determinism Builder: Chains Phase 1 Upstream Discovery → Shared Handoff Directory → Phase 2 V&V Scanners & 7-Gate False-Positive Validator → Phase 3 Executive Report + Evidence Annexes, verifying byte-for-byte reproducibility across consecutive runs (SHA-256 Run 1 == Run 2).
  • Unified 4-Provider Model Bar (Local Ollama + Gemini + Claude + OpenAI): Switch seamlessly between local onboard Ollama models (:11434) and cloud APIs across every stage—intent interviews, web-app translation, live 3-stage agent testing, feedback.json rewrites, and 60/40 trigger optimization.
  • PreToolUse Guardrails Lab & Native 2-in-1 AiLabs Embedding: Includes a 100-skill progressive-disclosure token router simulator, deterministic SQL/Bash/secret PreToolUse blocker (exit 2), clean-room portable INSTALL.md packaging targeting ~/.ailabs/config/skills/, and live MCP inspection + zero-copy skill discovery inside AiLabs.

Tech Stack

  • Skill Builder & Orchestrator Core: Python 3.10+ Standard Library (Zero External Pip Dependencies), Python AST Domain Extractor (skill_creator_studio.py), Sequential Pipeline Compiler (orchestrator_builder.py), 60/40 Trigger Optimizer & Guardrails Engine (enterprise_kit.py)
  • 4-Provider LLM House: Unified adapter (llm_bridge.py) supporting Local Ollama (/api/tags, /api/chat), Google Gemini (v1beta), Anthropic Claude (/v1/messages), and OpenAI (/v1/chat/completions)
  • Agent & Protocol Standards: Progressive-Disclosure SKILL.md Specification, Multi-Skill MCP Hub (2024-11-05 JSON-RPC 2.0, 56 tools / 20 resources verified via --self-test), Canonical JSON & SHA-256 Attestation
  • Verification Suite: Automated 17-test unittest suite (tests/test_skillforge.py) verifying Ollama discovery, AST decoupling, real subprocess eval loops, multi-skill 2-run SHA-256 determinism, PreToolUse guardrails, and clean-room hygiene

Theory & Architecture

Great agent skills aren't one-shot prompt blobs—they are software artifacts refined through empirical evaluation. SkillForge AI brings the complete internal meta-skill workflow to every user in a visual studio (and natively inside AiLabs): decoupling pure domain Python from web apps via AST analysis, proving measurable value through paired with_skill vs. baseline subprocess benchmarks (grading.json & benchmark.json), preventing trigger overfitting with a 60/40 train/test split, and composing individual skills into cryptographically deterministic multi-stage pipelines.

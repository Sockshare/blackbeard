Blender Generator: Zero-UI Multi-Agent 3D Studio

Overview

Blender Generator is a zero-UI, multi-agent 3D production studio integrated into Run Nexus. Instead of manually extruding meshes or painting weights in a GUI, a hierarchical team of LLM Director and Worker agents translates high-level creative briefs into executable Blender 5.0 Python (bpy) scripts—running Blender headlessly in subprocess sandboxes, inspecting scene telemetry and render passes, self-correcting script exceptions, and exporting game-ready GLB/FBX characters, animations, and procedural environments.

Key Capabilities & Agentic Features

  • Hierarchical Director & Worker Agent Loop: Decomposes complex 3D briefs into geometry, procedural PBR shader graphs, armature rigging, animation keyframes, lighting, and camera choreography subtasks.
  • Self-Healing Headless Blender 5.0 Execution: Executes generated bpy scripts against headless Blender 5.0, capturing stdout/stderr tracebacks and scene bounding-box diagnostics so agents automatically repair geometry or API errors.
  • Procedural Rigging, Morphs & Secondary Physics: Automates skeletal armatures, proportion morph targets, Mixamo animation retargeting, and cloth/spring secondary-motion physics.
  • Procedural Environments & Spatial 3D Audio: Synthesizes terrain, atmospheric lighting, procedural scattering, and 3D spatialized soundscapes ready for interactive engines.

Architecture & Tech Stack

  • 3D Engine: Headless Blender 5.0, Blender Python API (bpy), Procedural Geometry & Shader Nodes
  • Agentic Pipeline: Multi-Agent Director/Worker Orchestration, Gemini Pro Code Synthesis, Automated Traceback Recovery
  • Studio Frontend: Python Flask Server, Live Render Preview Gallery, GLB / FBX / MP4 Artifact Exporter

Engineering Philosophy & Systems Theory

3D content creation has historically been bottlenecked by steep GUI complexity. Because Blender exposes virtually every mesh operator, modifier, shader node, and bone constraint through its Python API, treating 3D modeling as a compiler-verified code-generation problem lets multi-agent LLMs build, rig, and animate parametric 3D worlds programmatically.

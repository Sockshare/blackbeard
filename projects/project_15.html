Agentic Taskmasters: Feedback Triage & Benefits Auto-Filer

Summary

Agentic Taskmasters brings together three high-impact workflow automations engineered across Run Nexus and the All Things Agentic Hackathon: (1) the Feedback Triage Taskmaster—an autonomous FastAPI + Gemini + Google Cloud Firestore agent that ingests noisy user feedback, deduplicates semantic clusters, scores severity, and dispatches actionable engineering tickets; (2) the Privacy-First Benefits Auto-Filer—a hybrid edge/cloud architecture pairing local Gemma models for zero-leakage PII scrubbing with cloud Gemini reasoning to map complex eligibility rules and auto-populate government PDF forms; and (3) the Run Nexus Google Drive API Automation Tool.

Key Features

  • Autonomous Feedback Triage Taskmaster: Built for the All Things Agentic Hackathon—combines FastAPI, Gemini structured tool-calling, and Cloud Firestore to classify sentiment, detect duplicate bug reports, assign priority, and draft engineering specs automatically.
  • Hybrid Edge/Cloud Privacy Architecture (Gemma + Gemini): Runs a local Gemma model on-device to tokenize and redact SSNs, addresses, and medical/financial PII before sending sanitized context to cloud Gemini for complex policy reasoning—re-hydrating fields locally onto target PDFs.
  • Deterministic PDF AcroForm & Coordinate Mapper: Programmatically inspects PDF form schemas and synthesizes validated field payloads to turn intimidating 20-page applications into guided 3-minute flows.
  • Google Drive & Workspace API Tooling: Integrated Run Nexus microservice (port 8080) managing OAuth2 scopes, automated folder provisioning, document conversion, and cloud artifact syncing.

Tech Stack

  • Cloud & Edge LLMs: Google Gemini API (Cloud Structured Reasoning), Local Gemma (On-Device PII Redaction)
  • Backend & Database: Python, FastAPI, Flask, Google Cloud Firestore, PyPDFForm / ReportLab
  • Integrations: Google Drive & Workspace REST APIs, OAuth 2.0, Asynchronous Webhook Workers

Theory & Architecture

Real-world enterprise AI adoption hinges on two questions: 'Can the agent take reliable action in production databases?' and 'How do we protect sensitive user PII?' Pairing cloud frontier models (Gemini) for deep reasoning with lightweight local open-weights models (Gemma) as a cryptographic-style privacy airlock unlocks automation for regulated healthcare, financial, and civic workflows.

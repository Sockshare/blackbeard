SkillForge AI: Web-App-to-LLM-Skill & MCP Compiler Studio

Summary

SkillForge AI is a zero-dependency, local-first Web-App-to-LLM-Skill & MCP Compiler Studio (Port 8108) and live agent testbench. Point it at any local web application folder, OpenAPI 3.1 service, Python/TypeScript codebase, or security/GRC blueprint and it extracts HTTP routes and functions, compiles a portable 5-artifact Agent Skill bundle (SKILL.md, mcp_server.py JSON-RPC 2.0, scripts/engine.py, references/schema.json, and tests/test_skill.py), installs it into a unified Multi-Skill MCP Hub, and lets you test live LLM-to-App tool calls in the browser.

Key Features

  • 2-Step PC Application Folder Scanner & Multi-Tool Extractor: Scans any local application directory (including a bundled companion reference web app, TaskPulse on Port 8110), automatically discovering HTTP API routes and functions and exposing each as a namespaced MCP tool and skill://<slug>/SKILL.md MCP resource.
  • Live 3-Stage Skill ↔ LLM Agent Testbench (Local Ollama Default + Optional Cloud APIs): Runs end-to-end tool execution using a local onboard Ollama model (:11434) by default or optional Google Gemini, OpenAI, Anthropic Claude, and custom OpenAI-compatible endpoints: (1) LLM reads SKILL.md and selects the MCP tool + JSON arguments, (2) Skill invokes the live HTTP endpoint or engine, and (3) LLM synthesizes a grounded answer from the live JSON response.
  • 6 Built-In Industry Presets (CLI & MCP Ready): Ships with production-ready presets for AWS IAM Least-Privilege Auditor, Kubernetes Zero-Trust Network Verifier, AICPA SOC 2 Continuous Control Monitor, GDPR/CCPA PII Dataflow Lineage Scanner, OpenAPI 3.1 IDOR Authorization Triage Engine, and Cloud FinOps Cost Anomaly Detector.
  • 4-Stage Compiler & 5-Gate AST Security + 3-Run SHA-256 Determinism Verifier: Validates YAML frontmatter, inspects generated Python AST for unsafe calls or hardcoded secrets, validates JSON Schema Draft 2020-12 contracts, executes 3 consecutive runs to prove SHA-256(Run 1) == SHA-256(Run 2) == SHA-256(Run 3), and verifies MCP JSON-RPC 2.0 handshakes.
  • 1-Click Claude Desktop / Cursor / Windsurf MCP Hub Config: Exports ready-to-paste mcpServers configurations serving all installed workspace skills over stdio and HTTP.

Tech Stack

  • Compiler & Workspace Core: Python 3.10+ Standard Library (Zero External Dependencies), Route & AST Function Extractor, Canonical JSON Serializer, Deterministic ZIP Packager, SHA-256 Digest Engine
  • Agent & Protocol Standards: Open Agent SKILL.md Specification, Multi-Skill Model Context Protocol Hub (MCP 2024-11-05 JSON-RPC 2.0 tools/list, resources/list, tools/call), JSON Schema Draft 2020-12
  • LLM Bridge & Companion Web App: Local Ollama Onboard Runtime (:11434 Default) + Optional Gemini / OpenAI / Anthropic / vLLM Profiles + Bundled TaskPulse Web App (examples/taskpulse-webapp)
  • Verification Suite: Automated 11-test unittest suite (tests/test_skillforge.py) verifying PC folder scanning, multi-skill MCP namespacing, live TaskPulse LLM tool execution, 3-run SHA-256 determinism, and zero proprietary content

Theory & Architecture

Turning existing internal web applications and security scripts into reliable AI agent skills usually stalls on brittle glue code and unverified tool schemas. SkillForge AI separates LLM tool routing (reading structured SKILL.md contracts via Local Ollama or Cloud APIs) from deterministic tool execution (typed MCP JSON-RPC handlers and canonical SHA-256 verified Python engines), letting engineers compile any web app into a live, testable agent skill in seconds.

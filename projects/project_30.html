LingoForge: 10-Language Gamified Learning, Half-Life SRS & AI Roleplay Studio

Summary

LingoForge is an independent, self-hosted 10-language learning web application and CLI built with Flask and SQLite. It combines CEFR-aligned skill trees, 8 interactive exercise mechanics, voiced dialogue stories, non-Latin script trainers, Half-Life Regression spaced repetition, and Levenshtein typo-tolerant grading with AI-powered grammar explanations, live conversational roleplay missions, and on-demand custom unit synthesis.

Key Features

  • 10 Complete Language Courses with Non-Latin Script Trainers: Supports Spanish, French, Japanese, German, Italian, Korean, Mandarin Chinese, Portuguese, Russian, and Arabic—including dedicated trainers for Hiragana/Katakana, Hangul, Cyrillic, Arabic Abjad, and Pinyin tones.
  • 8 Interactive Exercise Mechanics & Voiced Stories: Multiple-choice translation, word-bank tile assembly, normal/slow listening comprehension, free-type input with diacritic bars, tap-pair matching, cloze fill-in-the-blank, visual card selection, and speaking checks, plus interactive multi-character stories.
  • Half-Life Regression SRS & Levenshtein Typo Grader: Models per-word recall probability $p = 2^{-\Delta t / h}$, adapts memory half-life $h$ on every review, separates 1-edit typos from conceptual errors, and logs misses to a Mistakes Inbox for targeted weak-word restoration.
  • AI Tutor ("Explain My Answer"), Roleplay Missions & Custom Units: Delivers token-by-token grammar breakdowns, multi-turn roleplay missions with CEFR coaching tips, and custom topic unit generation via Gemini (google-genai) with deterministic offline fallbacks.
  • Neural Edge-TTS Caching & 1:1 CLI Parity: Synthesizes and caches SHA-256-indexed MP3 speech via edge-tts (falling back to browser Web Speech API offline) and exposes every engine action through cli.py.

Tech Stack

  • Learning & SRS Engine: Python, Flask, SQLite State Persistence, Half-Life Regression Spaced Repetition, Levenshtein Distance Grader
  • Conversational AI & Speech: Google GenAI SDK (Gemini) with Deterministic Offline Fallbacks, Microsoft Neural edge-tts Audio Synthesizer & Cache
  • Frontend & CLI: Responsive Single-Page Web App (Light/Dark Theme, Web Speech API) + cli.py Terminal Interface
  • Verification: Python unittest Suite verifying 10-language course generation, SRS state transitions, Levenshtein grading, and offline AI tutor responses

Theory & Architecture

Effective language acquisition requires pairing structured, low-friction repetition with open-ended conversational production. LingoForge unifies both in a local-first architecture: a mathematical Half-Life Regression scheduler governs vocabulary retention and typo-tolerant drills, while roleplay scenarios and structured grammar explanations let learners practice unscripted dialogue with or without an external cloud API key.

AiLabs: 4-Provider Agentic Coding IDE & Multi-Agent Runtime

Summary

AiLabs (Port 8120, integrated directly into Run Nexus and bridged with SkillForge AI) is a clean-room, zero-dependency Agentic Coding IDE, CLI, and Autonomous Multi-Agent Runtime engineered for both individual developers and entire engineering organizations. Instead of locking your agentic tooling, skills, subagents, and hooks to a single proprietary cloud vendor, AiLabs unifies Local Ollama (any installed onboard model) alongside Google Gemini API, Anthropic Claude API, and OpenAI API under one identical 22-tool runtime.

Key Features

  • 4-Provider Model House & 4-Tier Model Routing (inherit, pro, flash, flash_lite): Translates tool schemas, thinking traces, and multi-turn ReAct messages across Local Ollama (127.0.0.1:11434, including dynamic CPU prefill compaction and fenced-JSON fallback parsing for 3B/7B models), Google Gemini (functionDeclarations), Anthropic Claude (tool_use + thinking blocks), and OpenAI (function calls).
  • Complete 22-Tool Native Agent Suite: Implements 1-indexed file slicing & binary media inspection (view_file), whitespace-tolerant + Python AST-verified surgical edits (replace_file_content, multi_replace_file_content, write_to_file), fast search (list_dir, find_by_name, grep_search), async/persistent shell execution (run_command + manage_task), parallel subagents (define_subagent, invoke_subagent with git worktree isolation, manage_subagents, send_message), conditional timers & crons (schedule), Eager/Lazy MCP tools, web readers, local SVG/PNG UI mockup synthesis (generate_image), and interactive user governance modals (ask_question, ask_permission).
  • 6-Part Organizational & Personal Customization Engine (6-Tier Precedence): Discovers Rules (always_on, manual, glob, model_decision), Progressive-Disclosure Skills (SKILL.md), Custom Agents, Plugins, Lifecycle Hooks (PreToolUse/PostToolUse with exit 2 deterministic hard-blocks), and MCP Servers across 6 priority tiers—from repo-shared team standards (.ailabs/shared/) to personal overrides and automatic SkillForge AI skill discovery.
  • Reactive Auto-Wakeup, Brain Transcripts, Context Compaction & Sidecars: Stores per-session artifacts, scratch/ scripts, and dual JSONL transcripts (transcript_full.jsonl + token-efficient transcript.jsonl) with sliding-window <CONTEXT_SUMMARY> compaction, resumes idle sessions automatically when background tasks/subagents/timers finish, and runs persistent sidecars/ + the bin/agentapi CLI.
  • 3-Pane Cyber-Neon Web IDE & 8 Slash Workflows: Pairs a clickable workspace explorer & line-jump code editor (file:///path#L10) with a streaming ReAct chat & tool inspector, right-hand Artifact/Diff/Carousel/Task drawer, and 8 built-in slash workflows (/plan, /goal, /schedule, /grill-me, /learn, /owl, /teamwork-preview, /browser).

Tech Stack

  • Runtime & Tool Core: 100% Python 3.10+ Standard Library (Zero External Pip Dependencies), Multi-Turn ReAct Orchestrator (agent_loop.py), 22 Native Tools (tools.py), Git Worktree Subagent Isolation
  • Model House & MCP Hub: Unified 4-Provider Schema & Thinking Adapter (providers.py), Eager + Lazy Schema-File MCP JSON-RPC 2.0 Client (mcp_hub.py)
  • Customizations, Brain & Sidecars: 6-Level Precedence & Hook Engine (customizations.py), Dual-Transcript & Compaction Brain (brain.py), Continuous Daemon Sidecars (sidecars.py), bin/agentapi CLI
  • 3-Pane Web IDE & Verification: Vanilla HTML5/CSS3/ES6 IDE (GitHub Alerts, Unified Diffs, Carousels, Interactive Modals) + 7-Suite Automated Verification (tests/test_ailabs.py)

Theory & Architecture

Modern agentic coding environments succeed not because of a single prompt, but because of systems architecture: progressive skill disclosure that protects the context window, lazy MCP schema files that avoid bloating every turn with 100 tool definitions, deterministic PreToolUse hooks (`exit 2`) that stop destructive commands before execution, isolated git worktree branches so parallel subagents never clobber each other's edits, and reactive message wakeups that eliminate wasteful polling loops. AiLabs packages that entire architecture into a portable, provider-agnostic IDE that runs offline on local Ollama or scales up to frontier Gemini, Claude, and OpenAI APIs.

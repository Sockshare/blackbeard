SkillForge AI: Web-App-to-Agent-Skill (SKILL.md) & MCP Server Compiler Studio

Summary

SkillForge AI is an interactive Web-App-to-Agent-Skill (SKILL.md), Deterministic Python CLI, and Model Context Protocol (mcp_server.py JSON-RPC 2.0) Compiler Studio. It transforms any OpenAPI 3.1 specification, policy blueprint, or enterprise security/compliance workflow into a portable, cryptographically deterministic AI agent skill bundle ready for Claude Code, Cursor, Windsurf, OpenAI Codex CLI, and any MCP-compatible runtime.

Key Features

  • 6 Verified Industry Templates (1-Click Load): Includes production-ready blueprints for AWS IAM Least-Privilege & Trust Policy Auditor, Kubernetes Zero-Trust Network & Pod Security Verifier, AICPA SOC 2 Type II Continuous Control Monitor, GDPR & CCPA PII Dataflow Lineage Scanner, OpenAPI 3.1 IDOR & Source-to-Sink Authorization Triage Engine, and Cloud FinOps Waste & GPU Cost Anomaly Detector.
  • 4-Stage Multi-Agent Compiler Pipeline: Runs Stage 1: Workflow & Schema Architect (JSON Schema Draft 2020-12 contract extraction), Stage 2: Deterministic Engine Synthesizer (zero-dependency Python CLI & MCP server generation), Stage 3: 5-Gate Quality, Security & Determinism Verifier, and Stage 4: Multi-Artifact Packager (producing a deterministic .zip bundle).
  • 5-Gate Quality, AST Security & 3-Run SHA-256 Determinism Verification: Validates YAML frontmatter compliance, scans generated Python AST for dangerous calls or hardcoded secrets, verifies JSON Schema tool contracts, executes 3 consecutive runs to prove SHA-256 Run 1 == Run 2 == Run 3, and tests live MCP JSON-RPC 2.0 handshakes.
  • Live MCP JSON-RPC 2.0 Playground: Interactive request/response console supporting initialize, tools/list, and tools/call against any compiled skill with latency telemetry and cryptographic output digests.
  • Dual-Mode Execution (Full-Stack Server + Static GitHub Pages + 1:1 CLI): Runs both as a Python HTTP API + CLI + stdio MCP server and as a 100% client-side web studio in the browser.

Tech Stack

  • Compiler & Verification Core: Python 3.11+, AST Static Security Analyzer, Canonical JSON Serializer, Deterministic ZIP Packager, SHA-256 Digest Engine
  • Agent & Protocol Standards: Open Agent SKILL.md Specification (YAML Frontmatter + Guardrails), Model Context Protocol (MCP 2024-11-05 JSON-RPC 2.0 over stdio & HTTP), JSON Schema Draft 2020-12
  • Frontend Workbench: Vanilla ES2022 JavaScript, Web Crypto API (crypto.subtle.digest SHA-256), Responsive Dark-Mode Studio UI
  • Verification Suite: Automated unittest suite (tests/test_skillforge.py) verifying all 6 presets, 3-run determinism, extracted ZIP CLI execution, MCP JSON-RPC protocol compliance, and zero proprietary strings

Theory & Architecture

Modern AI agents fail in regulated enterprise environments when they rely on unconstrained LLM improvisation for calculations, security checks, or compliance audits. SkillForge AI solves this by separating agent orchestration (SKILL.md instructions and MCP tool discovery) from deterministic execution (synthesized Python engines with canonical key ordering and volatile-timestamp stripping). Every compiled skill is mathematically verified across three independent runs before packaging.

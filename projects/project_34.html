TrustForge SOC 2: Autonomous SOC 2 Type II Audit, 7-Gate Exception Triage & Privacy Crosswalk Studio

Summary

TrustForge SOC 2 is an open-source, deterministic AICPA SOC 2 Type I & Type II readiness, continuous evidence evaluation, and multi-framework compliance studio. Covering all 5 Trust Services Categories (Security CC1–CC9, Availability A1, Processing Integrity PI1, Confidentiality C1, and Privacy P1–P8), it automates AICPA audit sampling, runs a 7-Gate adversarial exception triage engine to distinguish True Positive control deviations from False Positives mitigated by compensating controls, audits upstream vendor SOC 2 CUECs and Bridge Letters, and generates cryptographically hashed Section III/IV auditor workpapers.

Key Features

  • All 5 AICPA Trust Services Categories (28 Criteria + 2022 Revised Points of Focus): Evaluates live technical telemetry across AWS (IAM, S3, KMS, RDS, GuardDuty, CloudTrail), Okta Workforce OIDC/WebAuthn MFA, GitHub Enterprise branch protection & SLSA provenance, Kubernetes RBAC, and PostgreSQL/Snowflake encryption.
  • AICPA Audit Guide Type I vs. Type II Sampling Calculator: Dynamically computes point-in-time design tests (Type I) versus 3-, 6-, and 12-month operating effectiveness sample sizes (Type II — e.g., 45 daily samples, 25 weekly samples, 10%–25% capped change/access populations totaling 661 samples per annual audit).
  • 7-Gate Adversarial Exception & Compensating Control Triage Engine: Inspects flagged alerts across Gates 0–6 (Boundary Scope, Network Reachability, Compensating Controls such as AWS Organization SCPs & statutory GDPR Art. 12(3) extensions, Data Classification, Remediation SLA, and Audit Materiality) to separate reportable Section IV deviations from mitigated False Positives.
  • Subservice Organization (Vendor) SOC 2 CUEC & Bridge-Letter Analyzer (CC9.2): Evaluates Carve-Out vs. Inclusive vendor SOC 2 reports (AWS, Okta, Snowflake, Stripe, Auth0), calculates report-end-date coverage gaps, verifies Bridge Letters, and maps every Complementary User Entity Control (CUEC) to internal customer controls.
  • 6-Framework Regulatory & Privacy Crosswalk + Portable MCP & SKILL.md: Maps all 28 SOC 2 criteria to ISO/IEC 27001:2022, NIST SP 800-53 Rev. 5, HIPAA, GDPR, and PCI-DSS v4.0, and ships with a standalone MCP JSON-RPC 2.0 server and 3-run SHA-256 determinism verification.

Tech Stack

  • Audit & Triage Engine: Python 3.11+ (trustforge_engine.py), AICPA Sampling Solver, 7-Gate Exception Triage State Machine, Vendor CUEC & Bridge-Letter Evaluator
  • Frameworks Supported: AICPA SOC 2 (2017 TSC / 2022 Points of Focus), ISO/IEC 27001:2022, NIST SP 800-53 Rev. 5, HIPAA Security & Privacy Rules, GDPR (EU 2016/679), PCI-DSS v4.0
  • Web Studio, CLI & MCP Server: Zero-dependency Python REST Server (server.py), Headless CLI (cli.py), Model Context Protocol JSON-RPC 2.0 Server (mcp_server.py), Open Agent SKILL.md, Client-Side Web Crypto SHA-256 Engine
  • Verification: Automated 10-test unittest suite (tests/test_trustforge.py) verifying all 4 cloud scenarios, 7-Gate verdicts, CUEC gap detection, 3-run SHA-256 determinism, and zero proprietary content

Theory & Architecture

Traditional GRC platforms treat SOC 2 as a static checklist of screenshots, leaving engineering and security teams scrambling when an auditor asks whether a raw scanner alert represents a true Section IV control deviation or a mitigated non-issue. TrustForge SOC 2 codifies AICPA sampling mathematics, 7-Gate compensating-control reasoning, and subservice CUEC lineage into a single deterministic engine where every management assertion and Section IV control table is reproducible to the exact SHA-256 digest.
